🗺️ Welcome to the Interactive Map Viewer!

Thank you for visiting! This application helps you visualize and explore geographic data in an interactive way.

Key Features:

  • 📁 Upload GeoJSON Files: Load your own geographic data and visualize it instantly
  • 🗺️ Multiple Basemaps: Switch between topographic, satellite, streets, and more
  • 🔍 Search Locations: Find any place in the world with the search tool
  • 📍 Add Markers: Place custom markers anywhere on the map
  • 📊 Interactive Legend: See symbols for all your loaded layers
  • 🎨 Layer Management: Control visibility and remove layers as needed

Getting Started:

1. Use the controls in the top-right corner to change basemaps and locations
2. Upload a GeoJSON file to see your data on the map
3. Click features to see their information in popups
4. Use the legend in the bottom-left to understand your data

💡 Tip: Try uploading a GeoJSON file to get started!
